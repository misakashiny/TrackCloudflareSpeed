# NAS Domain Optimizer — 管理界面

这是域名优选管理界面的源码快照，适配已有的 NAS Domain Optimizer 1.10 状态和控制接口。

**本仓库当前仅提供前端，不是完整的一键部署项目。** 不包含后台优选引擎、下载器连接适配器、Docker 部署配置、站点清单或任何真实运行数据。没有兼容后端时，页面会显示连接失败，不会产生优选效果。

## 页面

- 总览：服务状态、连接覆盖与需要留意的站点。
- 站点：搜索、筛选、域名维护、实际汇报及站点策略。
- 优选效果：公开连接对照、实际流量、诊断、周期报告和稳定性趋势。
- 记录：检测历史、配置操作和日志。
- 设置：保存的策略与执行证据；专项试验放在高级区域。

公开 HTTPS 探测、Tracker 自然汇报和文件传输是不同证据。页面不把连接耗时改善解释为下载速度提升，不把未采集记录当作正常，也不把待汇报备用地址当作失败。

## 使用边界

前端通过同源 `/api/status` 获取状态，沿用后端已有的站点、策略、日志、更新及有限试验接口。写操作携带后端下发的 CSRF 标记；认证、授权、参数检查、并发版本检查及恢复保护必须由兼容后端实现，不能依赖前端禁用按钮作为安全边界。

打开页面只读取状态。新增站点、保存策略、主动检测以及高级试验由对应按钮触发；它们仍具有各自的后台效果。新增优选域名不会替换下载器任务中的 Tracker URL。

侧栏主机名称来自当前浏览器地址，源码不固定部署地址。采用系统字体，不需要外部字体或 CDN。

## 验证

需要 Node.js 18 或更新版本，无第三方测试依赖：

```sh
node tests/ui.test.cjs
```

测试使用手写的合成域名和状态，不连接 NAS。覆盖状态区分、域名输入、视图分离、空日志防循环、断线/恢复显示、断线保存保护及交互期间延后自动刷新。代码检查和合成测试不能代替真实浏览器交互、后端接口或长期传输验收。

## 更新已有部署

仅适用于已经具备上述兼容后端的部署。先备份当前前端并核对接口版本，比较 `web/` 内文件后再更新；保留后台程序、配置和运行目录。不要把整个部署目录加入 Git。

本次版本为 `ui-20261104.2`，后端版本未变。本仓库没有发布完整服务安装包，也没有配置自动部署工作流。

## 隐私

本仓库只包含静态界面、合成测试和说明。不要提交 `runtime/`、`config/`、环境变量文件、诊断包、站点快照、截图或恢复备份。诊断日志即使已进行凭据脱敏，也可能暴露站点域名、网络地址和使用记录，分享前须检查。
